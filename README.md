# password-strength-analysis
Created and evaluated passwords of varying complexity to understand password security, strength metrics, and common attack methods.

Password Strength Analysis

Objective

To understand what makes a password strong and evaluate password strength using an online password strength checker.

Tools Used

* PasswordMeter (Online Password Strength Checker)

⸻

Deliverables

* Password strength evaluation report
* Password complexity analysis
* Security recommendations and best practices

Feedback from Password Strength Evaluation

The evaluation showed that password strength increases when:

* Password length is increased.
* Uppercase and lowercase letters are combined.
* Numbers are included.
* Special characters are used.
* Common dictionary words are avoided.

The evaluation also showed that short passwords and predictable patterns significantly reduce password security.

⸻

Best Practices for Creating Strong Passwords

* Use at least 12–16 characters.
* Include uppercase and lowercase letters.
* Use numbers and special characters.
* Avoid common words and phrases.
* Avoid personal information such as names and birthdays.
* Use unique passwords for each account.
* Enable Multi-Factor Authentication (MFA).
* Consider using a password manager.

⸻

Common Password Attacks

Brute Force Attack

A brute force attack attempts every possible combination of characters until the correct password is found. Longer and more complex passwords significantly increase the time required for a successful brute-force attack.

Dictionary Attack

A dictionary attack uses lists of commonly used passwords and dictionary words to guess passwords. Passwords such as “password123” are highly vulnerable to this attack.

Credential Stuffing

Credential stuffing occurs when attackers use username-password combinations leaked from previous data breaches to access other accounts. Reusing passwords across multiple services increases this risk.

⸻

Lessons Learned

* Password length is one of the most important factors in password security.
* Adding numbers and special characters improves password strength.
* Common words and predictable patterns weaken passwords.
* Long and unique passwords provide better protection.
* Password complexity directly affects resistance to cyberattacks.

⸻

How Password Complexity Affects Security

Password complexity plays a critical role in protecting accounts from unauthorized access. Complex passwords increase the number of possible combinations that attackers must try, making brute-force and dictionary attacks much less effective. Passwords that combine length, character variety, and unpredictability provide the highest level of security.
